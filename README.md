## 🚀 Selected Engineering Projects

My projects focus on practical applications of intelligent embedded systems, autonomous robotics, computer vision, and automotive technologies.

### 01. Deep Learning Model Optimization for Automotive ECUs

**Field:** Automotive AI · Embedded AI · ADAS

Development and evaluation of an optimization pipeline designed to reduce the computational cost of deep learning models for resource-constrained automotive hardware.

**Technical approach:**
- CNN-based traffic-sign recognition using the GTSRB dataset.
- Structured model pruning to reduce complexity.
- INT8 post-training quantization.
- Knowledge distillation to recover predictive performance.
- Quantization-aware training for improved accuracy.
- Inference latency, timing variability, and memory analysis.
- Discussion of real-time constraints and ISO 26262-related engineering considerations.

**Reported experimental results:**
- Classification accuracy: **93.8%** after quantization-aware training.
- Inference latency: **9.5 ms**, compared with 45.2 ms for the original model.
- Model storage: **12.8 MB**, compared with 65 MB originally.

*Academic research prototype. The experimental results do not establish ISO 26262 certification or automotive production readiness.*

**Technologies:** Python · PyTorch · YOLO · ONNX · INT8 Quantization

*Dedicated source repository being prepared.*

### 02. Autonomous Robotic Chair — ROS 2 Navigation

**Field:** Autonomous Robotics · SLAM · Robot Navigation

Development of a simulated autonomous robotic chair capable of localization, mapping, and navigation in indoor environments.

**Main components:**
- Robot description using URDF.
- Gazebo simulation with indoor environments.
- LiDAR and IMU integration.
- Mapping with SLAM Toolbox.
- Localization using Adaptive Monte Carlo Localization (AMCL).
- Navigation architecture based on ROS 2 and Nav2.
- Velocity-command control and obstacle-distance monitoring.

**Technologies:** ROS 2 · Python · Gazebo · Nav2 · SLAM · AMCL · URDF

[View ROS 2 Repository](https://github.com/ayman2218/ros2)

### 03. AI-Based Human Fall Detection

**Field:** Computer Vision · Human Pose Estimation · Intelligent Monitoring

Design of a fall-detection system combining visual perception and machine learning for human activity monitoring.

**Main components:**
- Human pose estimation using MediaPipe.
- Extraction and analysis of skeletal landmarks.
- Posture and motion-feature processing.
- Temporal activity classification using LSTM and BiLSTM.
- Evaluation using precision, recall, F1-score and confusion matrices.
- Prototype alerting functionality.

**Technologies:** Python · OpenCV · MediaPipe · TensorFlow · LSTM · Raspberry Pi

[View Fall Detection Repository](https://github.com/ayman2218/fall)

### 04. Robotic Arm for Autonomous Tic-Tac-Toe

**Field:** Robotics · Embedded Control · Mechatronics

Development of a five-servo robotic arm designed to interact with a physical tic-tac-toe board.

**Main components:**
- Embedded actuation based on Arduino UNO.
- PCA9685 PWM controller for servo control.
- Mechanical positioning through predefined joint configurations.
- Sequential control of arm movement and gripper operation.
- Game logic, turn management, and victory detection.

**Technologies:** Arduino · C/C++ · PCA9685 · Servo Motors · Robotics
